# Resource packs

Content here is inactive reference material. A resource becomes part of the
game only after selected files are copied to their correct runtime locations,
their provenance is recorded, and the result is play-tested.

The pre-existing collection at `Graphics/Graphics/` follows this same policy,
but remains in place to keep the initial cleanup commit reviewable.

Do not bulk-merge a pack into `Graphics/`, `Audio/`, `PBS/`, or `Data/`.
